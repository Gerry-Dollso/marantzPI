# marantzPI

A modern Raspberry Pi companion display for Marantz and Denon HEOS receivers.

marantzPI transforms an official Raspberry Pi 7" touchscreen into a dedicated "Now Playing" display, showing album artwork, track information, playback status and receiver information in a clean, hi-fi inspired interface.

Designed to complement Marantz and Denon equipment rather than distract from it.

---

## Features

- 🎵 Automatic Now Playing screen
- 🕒 Elegant idle clock when playback stops
- 🖼️ Album artwork display
- 📀 Track, artist and album information
- 🔊 Live receiver volume and mute status
- 🎚️ Playback controls
- 🔄 Custom input names (e.g. NET → TIDAL)
- 💾 Automatic backup before every software update
- ⚡ Optimised for the official Raspberry Pi 7" touchscreen

---

## Hardware Requirements

- Raspberry Pi 4 (or newer)
- Official Raspberry Pi 7" Touch Display
- Marantz or Denon AV Receiver with HEOS
- Network connection
